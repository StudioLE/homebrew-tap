# StudioLE/homebrew-tap

Personal Homebrew tap for StudioLE applications, plus formulas for a few tools that aren't in Homebrew core.

## Install

Install any formula with:

```shell
brew install studiole/tap/<name>
```

## StudioLE applications

- [`alnwick`](https://github.com/StudioLE/alnwick) - self-hosted podcast library
- [`example`](https://github.com/StudioLE/example-rs) - template for Rust CLI projects
- [`hook-rs`](https://github.com/StudioLE/hook-rs) - permission hooks for Claude Code with bash-aware command analysis
- [`mount-luks`](https://github.com/StudioLE/mount-luks) - unlock and mount a LUKS encrypted disk, Linux only
- [`orbit`](https://github.com/StudioLE/Orbit) - deploy Docker Compose stacks with local configs and sops secrets
- [`surveyor`](https://github.com/StudioLE/surveyor-rs) - version a Cargo repo from git tags and conventional commits, and render release notes

> [!NOTE]
> Each release updates its formula automatically. Report issues on the application's repo.

## Forks

- [`photo_sort`](https://github.com/StudioLE/PhotoSort) - rename and sort photos and videos by their EXIF date, forked from [`0xCCF4/PhotoSort`](https://github.com/0xCCF4/PhotoSort)

- [`cloudflare-cf`](https://developers.cloudflare.com/cf/) - Cloudflare CLI for the entire Cloudflare API, installs as `cf`
